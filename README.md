## Problem
Controlled empirical comparison of four learning algorithms on the UCI Breast Cancer Wisconsin (Diagnostic) dataset (`wdbc.data`). The positive class is malignant.

## Algorithms
- Logistic Regression
- k-Nearest Neighbours
- Random Forest
- RBF Support Vector Machine

All algorithms use the same repeated stratified outer folds. Standardization is fitted **inside** each fold through a scikit-learn `Pipeline`. Each algorithm receives an equal six-configuration tuning budget using 3-fold inner cross-validation and ROC-AUC as the selection metric.

## Reproduce
In Google Colab or a Python environment:

```bash
pip install -r requirements.txt
python src/run_experiment.py
```

The script first attempts to download the official UCI `wdbc.data` file. If the UCI host is unavailable, it falls back to scikit-learn's packaged copy of the same 569 x 30 WDBC predictor matrix.

## Important runtime note
The four scikit-learn models run on the CPU. A Colab T4 GPU can be attached, but it is not used by these implementations. `results/environment.json` records the hardware and versions for the reference run.

## Key files
- `src/run_experiment.py` - end-to-end experiment
- `CPE513_P1_Colab_Notebook.ipynb` - Colab launcher and results viewer
- `results/fold_results_main.csv` - raw 15-fold scores per algorithm
- `results/oof_predictions_main.csv` - pooled outer-fold predictions
- `results/best_hyperparameters_by_fold.csv` - fold-specific tuning outcomes
- `results/wilcoxon_holm_balanced_accuracy_with_r.csv` - paired post-hoc tests
- `results/scaling_ablation_summary.csv` - scaling ablation
- `figures/` - report figures generated by code
- `requirements.txt` / `environment.yml` - pinned environments
